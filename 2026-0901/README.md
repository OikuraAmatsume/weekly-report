## 内容上の注記

- OpenAI 公式記事の公開日は 2026年2月4日です。「8月下旬にオープンソース化」という表現は一次情報と一致しないため、スライドでは公開時期を断定せず、公式記事の日付だけを図のキャプションに記載しました。
- OpenAI は Cursor へのモデル提供契約を終了する方針で、2026年11月12日を移行期限として提案しています。契約終了後も、OpenAI API key または Codex IDE 拡張を使う選択肢があります。
- Anthropic の Model Hardware Standard（MHS）は研究プレビュー段階で、公開標準の正式リリース前です。
- Gemini 3.5 Transcribe の話者分離は録音音声向けです。リアルタイム転写とは別の機能として記載しています。
- Codex は ChatGPT の対象プランに含まれますが、利用上限・追加クレジットはプランごとに異なります。
