# AIトピック｜朝会用HTMLスライド

6テーマ・日本語・約5分。動画視聴時間は含みません。

## 開き方

`index.html` をChromeなどのブラウザで開いてください。フォルダ全体を保管・共有してください。
左右矢印／PageUp・PageDown：移動。Home・End：先頭・末尾。F：全画面。N：発表メモ。画面下の「出典」で資料一覧を表示します。
動画はクリックで再生。自動再生しません。別のページに移ると停止します。外部リンクは別タブで開きます。

## テンプレート

指定された Blue Professional を使用。原テンプレートのクリーム色、コバルト、Space Grotesk / Inter、2列レイアウトとナビゲーションを継承し、日本語フォールバックと動画領域を追加。ユーザーがテンプレートを指定済みのため、候補の選択工程は省略。

## 日付と根拠

資料表示日：2026年11月3日。参照情報確認：2026年11月24日。11月3日以降の公開資料を含みます（Mirage発表記事は11月6日）。日付はニュースの情報締切ではありません。
Fable 5.5のモデル名・制作時間・制作過程は未検証。42AIの98%は各行動の的中率ではありません。RelayVSRの13.82GBは1080p時の測定です。MirageのOCRはラテン文字のみです。

## 映像と素材

動画はassetsに同梱。映像の権利は各作者・提供元に帰属します。素材の取得先はmedia-sources.jsonを参照してください。
- Fable：作者のHTMLに埋め込まれたThe Moss Keeperを抽出。音声あり。
- 42AI：公式サイトのイメージ映像。予測の実演ではありません。無音。
- Archon：Selendisの公式発表動画。音声あり・英語。
- hunch：公式の画像デモ画面2点と公式GIFをMP4に変換。ツール呼び出しの判断比較。無音。
- Mirage：公式記事の認識済みサンプルの各表示をキャプチャして動画化。新たな推論の実測ではありません。無音。
- RelayVSR：研究チームの公式比較動画。無音。

動画はローカル再生可能。公式リンクにはインターネットが必要です。発表原稿はsource/speaker-notes.md、編集用データはsource/topics.jsonです。
